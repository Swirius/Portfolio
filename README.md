Portafolio personal de **Junior Java Developer (Backend & Web)**. Enfoque en código claro, buenas prácticas y entrega de valor. Deploy en **GitHub Pages**.

## 🚀 Demo
- **Live:** https://swirius.github.io/ _(ajusta la URL si usás otra ruta o repo)_

## 📦 Stack
- **Frontend:** HTML5, CSS3, JavaScript (vanilla)
- **Hosting:** GitHub Pages
- **Contacto:** Formspree (POST) + `mailto:` como fallback
- **Meta:** Open Graph / Twitter Cards, `robots.txt`, `sitemap.xml`, JSON-LD (`Person`)
- **UX:** Responsive, accesible (foco visible, `alt` descriptivos, contraste)
- **Robustez:** Página `404.html` para rutas inválidas

## ✨ Secciones
- **Hero:** nombre, rol y CTA.
- **About:** perfil breve con mentalidad de producto.
- **Core Skills:** tecnologías principales.
- **Education & Certifications:** formación universitaria y bootcamps.
- **Projects:** proyectos destacados con bullets técnicos y enlaces.
- **Experience:** experiencia laboral formateada como “project cards”.
- **Contact:** formulario funcional + datos directos.
